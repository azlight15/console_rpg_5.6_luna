# console_rpg_5.6_luna

一个控制台回合制 RPG 项目。

这是原 `Console_RPG` 项目的独立 Luna 重构版本。

## 版本

**Luna v1.0.0**

v1.0 在 v0.5 的核心 RPG 循环上加入了基础经济系统和技能资源系统，让游戏形成更完整的“战斗 → 获得资源 → 消费 → 变强”循环。同时对核心代码补充了较完整的中文注释，方便回看代码时理解每个类为什么存在、数据在哪里修改。

### v1.0.0 更新内容

- 新增金币系统：击败怪物获得金币。
- 新增城镇商店：可以购买治疗资源、技能点和基础装备。
- 商店购买的装备会进入背包，不会自动替换当前装备。
- 新增技能点系统：技能具有不同资源消耗。
- 升级后技能点补满，战斗胜利后恢复少量技能点。
- 战斗界面显示金币和技能点。
- 状态界面显示金币、技能点和技能消耗。
- 存档新增金币与技能点，并对旧档提供默认值兼容。
- 怪物新增金币奖励，并随怪物等级成长。
- 保留 v0.5 的 10 种怪物、等级浮动、精英怪、装备掉落、稀有度、暴击和闪避。
- 补充 `Player`、`Battle`、`SkillSystem`、`DamageCalculator`、`MonsterFactory`、`SaveData` 等核心文件的解释性注释。

## 当前结构

- `Program.cs`：程序入口、启动流程和主菜单
- `Player.cs`：玩家状态、资源、装备、背包和最终属性计算
- `Equipment.cs`：装备数据模型
- `EquipmentFactory.cs`：随机掉落装备生成
- `EquipmentManager.cs`：背包和装备交互
- `Skill.cs`：技能数据模型
- `SkillSystem.cs`：技能资源检查与技能执行
- `DamageCalculator.cs`：普通攻击和技能伤害计算
- `Monster.cs`：怪物数据模型
- `MonsterFactory.cs`：怪物选择、等级生成和属性缩放
- `Battle.cs`：回合制战斗流程、奖励、掉落和死亡处理
- `LevelUp.cs`：经验结算与升级流程
- `Heal.cs`：非战斗治疗
- `ShowStatus.cs`：角色状态展示
- `Shop.cs`：城镇商店与金币消费
- `SaveData.cs`：JSON 存档、读档、删档和旧版本兼容

### 代码阅读建议

如果你是隔了一年再回来看的原作者，建议按下面的顺序理解：

```text
Program
  ↓ 调用
Player
  ↓ 保存所有玩家运行时状态
 ┌───────────────┬────────────────┬──────────────┐
 ↓               ↓                ↓              ↓
Battle        EquipmentManager  Shop         ShowStatus
 ↓               ↓                ↓
MonsterFactory  Inventory       Gold
 ↓
Monster

Battle
  ↓ 使用
SkillSystem → DamageCalculator

Battle
  ↓ 胜利
LevelUp + Gold + EquipmentFactory

SaveData
  ↕
Player
```

核心原则是：**UI/流程负责调用，Player 负责状态，Factory 负责创建，System 负责规则，SaveData 负责持久化。**

## 游戏循环

```text
创建角色 / 读取档案
      ↓
初始装备 + 技能 + 金币
      ↓
进入战斗
      ↓
根据玩家等级生成怪物
      ↓
攻击 / 技能 / 治疗 / 撤退
      ↓
击败怪物
      ↓
获得 EXP + 金币 + 概率装备
      ↓
升级 / 换装 / 消费资源
      ↓
城镇商店补充治疗与技能点
      ↓
继续冒险
```

## v1.0 战斗资源

技能现在需要技能点：

- `重击`：消耗 1 点
- `火球`：消耗 2 点

技能点上限随等级增长。升级后补满，普通战斗胜利后恢复 1 点；商店也可以购买 1 点技能点。

技能点的扣除逻辑集中在 `Player.TryUseSkillPoint()`，而技能伤害仍由 `SkillSystem` 和 `DamageCalculator` 分工处理。

## v1.0 经济系统

怪物击败后会给予金币。金币可以在主菜单进入“城镇商店”消费：

- 治疗药剂：20 金币
- 技能点药剂：30 金币
- 猎人短剑：80 金币
- 铁甲：100 金币

商店装备会进入背包，玩家需要进入“装备管理”手动换装。

## 装备系统

装备不会直接修改玩家基础属性，而是通过：

- `FinalAttack`
- `FinalMaxHp`
- `FinalCriticalRate`
- `FinalEvasionRate`

计算最终属性。

装备掉落目前采用三档稀有度：普通 70%、稀有 25%、史诗 5%。装备拥有攻击、生命、暴击、闪避等属性。

## 存档

存档系统支持多个本地档案，并保存：

- 玩家等级与经验
- 当前 HP
- 基础属性
- 当前武器和防具
- 完整装备库存
- 已学习技能
- 治疗资源
- 金币
- 技能点

新增字段带默认值，因此旧版存档缺少这些字段时仍可以读取。

## 注释策略

这个项目不是为了“每一行代码都写注释”，而是优先解释容易让未来的自己困惑的地方：

- **这个类负责什么？** → XML summary
- **为什么这样设计？** → 方法或关键逻辑附近解释
- **这个数值是什么意思？** → 属性注释
- **为什么这里不能直接改？** → 说明数据封装原因
- **为什么这里用 while / switch / 工厂？** → 说明实际解决的问题

这样既能帮助重新学习 C#，也不会让注释变成重复代码本身的废话。

## 当前限制

v1.0 仍然是一个轻量级控制台 RPG，没有加入大型 RPG 常见的复杂系统，例如：

- Boss 多阶段战斗
- 技能冷却真正进入战斗逻辑
- 状态效果（中毒、燃烧、眩晕等）
- 更完整的任务/地图系统
- 装备强化、出售、词缀重铸
- 自动化测试项目
- UI 框架或图形界面

这些内容可以在后续版本逐步加入，但会优先保持项目结构容易理解，而不是为了“看起来高级”无限增加抽象层。
