# console_rpg_5.6_luna

一个控制台回合制 RPG 项目。

这是原 `Console_RPG` 项目的独立 Luna 重构版本。

## 版本

**Luna v0.5.0**

本版本把 v0.4.0 的装备/战斗基础扩展成实际的 RPG 循环：打怪、升级、掉落、收集装备、换装，并让怪物等级随玩家等级变化。

### v0.5.0 更新内容

- 怪物数量扩展到 10 种：史莱姆、哥布林、骷髅兵、野狼、巨魔、黑暗法师、蝙蝠、兽人、冰霜巨兽、毒蛇。
- 怪物等级根据玩家等级生成，并在玩家等级上下 2 级范围内随机浮动。
- 不同怪物继续拥有不同的 HP、攻击、经验和闪避定位。
- 怪物属性会根据实际等级进行成长缩放。
- 保留 10% 精英怪机制，并让精英怪进一步获得属性强化。
- 装备新增普通、稀有、史诗三档稀有度。
- 装备新增攻击、生命、暴击、闪避四类属性。
- 新增 `EquipmentFactory`，负责随机装备掉落与稀有度生成。
- 玩家新增装备库存，战斗胜利后有概率获得装备。
- 装备管理升级为“背包 + 装备”界面，可从库存选择装备。
- 战斗状态显示最终攻击、暴击率和闪避率。
- 普攻暴击率现在使用玩家最终暴击属性。
- 玩家闪避率现在会影响怪物攻击。
- 经验曲线从固定线性公式调整为随等级逐步增加。
- 存档新增装备库存，同时兼容 v0.4 没有库存字段的旧档案。
- 更新 README 与开发记录。

## 当前结构

- `Program.cs`：程序入口与主菜单
- `Player.cs`：玩家角色实体、基础属性、最终属性、装备库存和技能状态
- `Equipment.cs`：装备数据模型与属性展示
- `EquipmentFactory.cs`：随机装备与掉落生成
- `EquipmentManager.cs`：背包与装备界面
- `Skill.cs`：技能数据模型
- `SkillSystem.cs`：技能初始化与技能执行
- `DamageCalculator.cs`：普通攻击和技能伤害计算
- `Monster.cs`：怪物数据模型
- `MonsterFactory.cs`：怪物生成、等级缩放和战斗定位配置
- `Battle.cs`：回合制战斗、技能、闪避、暴击与掉落
- `LevelUp.cs`：经验与升级
- `Heal.cs`：治疗资源管理
- `ShowStatus.cs`：角色状态显示
- `SaveData.cs`：JSON 存档与数据转换

玩家状态由 `Player` 实例管理，各系统通过参数访问玩家数据，不再依赖全局静态玩家状态。

## 游戏循环

```text
创建角色
  ↓
初始装备 + 技能
  ↓
进入战斗
  ↓
根据玩家等级生成怪物
  ↓
攻击 / 技能 / 治疗 / 撤退
  ↓
击败怪物
  ↓
获得 EXP + 概率获得装备
  ↓
升级 / 收集装备
  ↓
背包查看与换装
  ↓
最终属性变化
  ↓
继续冒险
```

## v0.5.0 装备系统

装备不会直接修改玩家基础属性，而是通过 `FinalAttack`、`FinalMaxHp`、`FinalCriticalRate` 和 `FinalEvasionRate` 计算最终属性。

装备掉落目前采用三档稀有度：

- 普通：70%
- 稀有：25%
- 史诗：5%

掉落装备拥有不同的武器/防具模板和属性组合。当前版本暂未加入装备出售、强化、套装和词缀重铸。

## v0.5.0 战斗系统

进入战斗后可以选择：

1. 普通攻击
2. 使用技能
3. 治疗
4. 撤退

怪物等级不再固定等于玩家等级，而是在玩家等级附近随机生成；精英怪会进一步提高等级和属性。

## 存档

存档系统支持多个本地档案，并保存：

- 玩家等级与经验
- 当前 HP
- 基础属性
- 当前武器和防具
- 完整装备库存
- 已学习技能
- 治疗资源

v0.5 新增的库存字段缺失时会按 v0.4 的当前装备自动补入库存，因此旧档案仍可继续使用。

## 设计方向

v0.5 的目标是先形成完整的核心 RPG 循环，而不是一次加入所有复杂系统。

暂不加入：

- Boss 战
- 技能 MP / 能量系统
- 技能冷却与复杂状态效果
- 装备强化与出售
- 自动化测试框架

这些内容可以留给 v1 的整理和进一步扩展阶段。
