# console_rpg_5.6_luna

一个控制台回合制 RPG 项目。

这是原 `Console_RPG` 项目的独立 Luna 重构版本。

## 版本

**Luna v0.3.0**

本版本从基础架构整理进入战斗系统扩展阶段，重点增强怪物设计与战斗反馈。

### v0.3.0 更新内容

- 扩展怪物系统，增加更多具有不同定位的敌人。
- 为怪物加入类型信息，区分肉盾、均衡、强攻、高速等战斗特点。
- 为怪物加入闪避率属性，为后续特殊能力扩展提供基础。
- 精英怪系统同步适配新的怪物属性。
- 战斗系统开始支持暴击、闪避等随机战斗机制。
- 更新战斗相关注释，说明伤害计算和战斗流程设计。
- 更新开发文档，记录当前版本变化和后续计划。

## 当前结构

- `Program.cs`：程序入口与主菜单
- `Player.cs`：玩家角色实体与自身状态管理
- `Monster.cs`：怪物数据模型
- `MonsterFactory.cs`：怪物生成和战斗定位配置
- `Battle.cs`：回合制战斗系统
- `LevelUp.cs`：经验与升级
- `Heal.cs`：治疗资源管理
- `ShowStatus.cs`：状态显示
- `SaveData.cs`：JSON 存档与数据转换

当前玩家状态由 `Player` 实例管理，各系统通过参数访问玩家数据，不再依赖全局静态玩家状态。

## v0.3.0 设计方向

怪物不再只是不同数值的敌人，而开始拥有不同战斗定位。

后续计划：

- 增加怪物特殊技能。
- 完善 Boss 战机制。
- 增加装备、技能和属性系统。
- 继续优化战斗策略深度。
