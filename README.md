# console_rpg_5.6_luna

一个控制台回合制 RPG 项目。

这是原 `Console_RPG` 项目的独立 Luna 重构版本。当前阶段重点整理玩家状态封装、输入校验、战斗流程、升级、怪物生成、治疗资源与 JSON 存档。

## 版本

**Luna v0.2.0**

本版本完成了从全局静态玩家状态到 `Player` 实例的进一步重构，并开始强化角色自身的数据封装与治疗资源管理。

### v0.2.0 更新内容

- `PlayerStatistics` → `Player` 实例，移除玩家状态对全局静态数据的依赖。
- `Player` 开始封装自身 HP 状态，通过方法修改生命值，而不是由其他系统直接赋值。
- 治疗资源由玩家统一持有，战斗内与场外治疗共用同一资源池。
- 场外治疗不再可以无限使用，避免通过反复进出战斗规避治疗限制。
- 升级时恢复满 HP，并获得额外治疗资源。
- JSON 存档同步保存和恢复治疗资源。
- 更新战斗、治疗、状态显示、升级和存档相关注释。
- 同步更新 `DevelopNotes.md`，记录当前架构与后续计划。

## 当前结构

- `Program.cs`：程序入口与主菜单
- `Player.cs`：玩家角色实体与自身状态管理
- `Monster.cs`：怪物数据模型
- `MonsterFactory.cs`：怪物生成
- `Battle.cs`：战斗系统
- `LevelUp.cs`：经验与升级
- `Heal.cs`：场外治疗
- `ShowStatus.cs`：状态显示
- `SaveData.cs`：JSON 存档与数据转换

当前玩家状态由 `Player` 实例管理，各系统通过参数访问玩家数据，不再依赖全局静态 `PlayerStatistics`。

治疗资源也属于 `Player` 状态的一部分，因此会随着存档保存和恢复，并由战斗、场外治疗和升级系统共同使用。
