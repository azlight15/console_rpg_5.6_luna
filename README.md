# console_rpg_5.6_luna

一个控制台回合制 RPG 项目。

这是原 `Console_RPG` 项目的独立 Luna 重构版本。

## 版本

**Luna v0.4.0**

本版本进入装备与技能系统阶段，重点是让玩家成长内容真正接入游戏流程，而不是只停留在数据模型。

### v0.4.0 更新内容

- 新增装备模型与装备管理入口。
- 新增武器、防具及其属性加成。
- 玩家拥有基础属性与装备后的最终属性，装备不会直接修改基础属性。
- 新游戏默认获得木剑、旅行皮甲以及两个基础攻击技能，方便直接测试 v0.4.0。
- 战斗菜单增加技能行动。
- 新增 `SkillSystem`，负责技能实际执行。
- 新增 `DamageCalculator`，统一处理普通攻击和技能伤害。
- 普通攻击与技能都支持暴击；怪物闪避会影响两种攻击。
- 状态界面显示装备、技能和最终属性。
- 存档支持保存和恢复装备、技能。
- 补充相关注释和开发文档。

## 当前结构

- `Program.cs`：程序入口与主菜单
- `Player.cs`：玩家角色实体、基础属性、装备和技能状态
- `Equipment.cs`：装备数据模型
- `EquipmentManager.cs`：当前版本的装备目录和装备界面
- `Skill.cs`：技能数据模型
- `SkillSystem.cs`：技能初始化与技能执行
- `DamageCalculator.cs`：普通攻击和技能伤害计算
- `Monster.cs`：怪物数据模型
- `MonsterFactory.cs`：怪物生成和战斗定位配置
- `Battle.cs`：回合制战斗流程与行动选择
- `LevelUp.cs`：经验与升级
- `Heal.cs`：治疗资源管理
- `ShowStatus.cs`：角色状态显示
- `SaveData.cs`：JSON 存档与数据转换

当前玩家状态由 `Player` 实例管理，各系统通过参数访问玩家数据，不再依赖全局静态玩家状态。

## v0.4.0 使用方式

新游戏开始后会自动装备基础装备并学习两个技能。

主菜单新增：

- `装备管理`：切换当前武器和防具。

进入战斗后可以选择：

1. 普通攻击
2. 使用技能
3. 治疗
4. 撤退

查看状态时可以看到基础攻击力、最终攻击力、最终生命上限、当前装备和已学习技能。

## 设计方向

装备只提供属性加成，玩家基础属性不会因为换装而被永久修改。

技能数据与技能执行逻辑分离：`Skill` 保存技能数据，`SkillSystem` 负责执行，`DamageCalculator` 负责伤害数值。这样后续增加治疗技能、状态效果或资源消耗时，不需要继续把所有逻辑堆进 `Battle`。

v0.4.0 的装备入口仍然是简化版本，目前没有完整背包、掉落、装备数量和稀有度系统。这些内容留给后续版本。
