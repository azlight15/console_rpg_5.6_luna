# console_rpg_5.6_luna

一个控制台回合制 RPG。

这是原 `Console_RPG` 项目的独立 Luna 重构版本。

## 当前版本

**Luna v1.5.1**

v1.5.1 的功能开发与实际游玩测试已经完成。当前阶段主要进行代码注释、项目文档和控制台 UI 的整理，不再主动改变已经通过测试的核心玩法。



## v1.5.1 修复内容

v1.5.1 根据第三方代码审查结果进行了一轮逻辑加固：

- 修复技能暴击率没有使用玩家装备暴击加成的问题。
- 修复战斗状态结算消息被后续清屏隐藏的问题。
- 满血时使用治疗不会再白白消耗一个战斗回合。
- 统一伤害计算使用 Random.Shared。
- 当前装备读档改用背包索引对齐，解决同名装备可能匹配错误的问题，同时保留旧存档名称匹配兼容。
- 增强存档中的装备、技能和资源数据校验。
- 统一升级系统类名为 LevelUp，与 LevelUp.cs 文件保持一致。
- 初始装备名称与掉落装备统一显示稀有度前缀。
- 新增同名装备读档对齐自动化测试。
- 状态伤害重复结算问题经代码检查未发现重复调用路径，因此没有为了“修复”而改动现有状态结算规则。

## v1.5.1 完成功能

### 主菜单与 UI

- 主菜单按「冒险 / 成长 / 城镇 / 存档」分区。
- 主菜单与各级子菜单统一使用数字 `0` 返回或退出当前层级。
- 装备、技能、商店等页面统一显示当前资源和操作提示。
- 装备列表统一使用 `[已装备]` 标记当前武器和防具。
- 第一场战斗保证生成普通怪物，从第二场开始才进入 10% 精英怪随机机制。

### 玩家与成长

- 玩家由 `Player` 实例统一维护运行时状态。
- 基础属性与装备加成分离，通过最终属性计算得到实际战斗数值。
- 经验、升级、HP、治疗资源、金币和战斗技能点均有独立规则。
- 升级会提升最大 HP 和攻击力，并恢复 HP、治疗资源和技能点。

### 技能

- 新角色默认获得：重击、火球。
- 新增可学习技能：冰枪、毒刃、旋风斩。
- 技能学习有最低等级和金币费用。
- 学习技能消耗金币；战斗中释放技能消耗技能点。
- 技能拥有冷却和部分状态效果。
- 技能管理界面显示已学习技能和可学习技能。

| 技能 | 学习等级 | 学习费用 | 战斗消耗 | 冷却 |
|---|---:|---:|---:|---:|
| 重击 | 1 | 免费 | 1 点 | 2 回合 |
| 火球 | 1 | 免费 | 2 点 | 3 回合 |
| 冰枪 | 3 | 80 金币 | 2 点 | 3 回合 |
| 毒刃 | 5 | 120 金币 | 1 点 | 2 回合 |
| 旋风斩 | 7 | 180 金币 | 3 点 | 4 回合 |

### 装备

装备不会直接修改玩家基础属性，而是通过最终属性计算：

- `FinalAttack`
- `FinalMaxHp`
- `FinalCriticalRate`
- `FinalEvasionRate`

当前装备系统支持：

- 普通、稀有、史诗三档稀有度
- 装备掉落
- 背包查看
- 装备切换
- 当前装备标记
- 装备出售
- 装备强化，最高 +5

强化规则：

- 武器每次强化增加 4 点攻击力。
- 防具每次强化增加 15 点最大 HP。
- 强化费用随强化等级和稀有度增加。
- 当前穿戴装备不能直接出售。

### 战斗

战斗采用回合制流程：

1. 普通攻击
2. 使用技能
3. 治疗
4. 撤退

战斗支持：

- 暴击
- 闪避
- 技能冷却
- 技能点
- 中毒
- 燃烧
- 眩晕
- 精英怪特殊攻击
- EXP、金币和装备掉落

怪物会根据玩家等级生成，通常处于玩家等级上下 2 级范围内。精英怪在此基础上获得等级、属性、奖励和特殊攻击强化。

### 商店

城镇商店支持：

- 购买治疗资源
- 购买技能点
- 购买基础装备
- 装备强化

商店只负责交互流程，金币和装备状态仍由 `Player` / `Equipment` 管理。

### 存档

存档系统支持多个本地档案：

- 创建档案
- 读取档案
- 删除档案
- 存储玩家等级与经验
- 存储 HP 和基础属性
- 存储当前武器、防具与完整装备库存
- 存储已学习技能
- 存储治疗资源
- 存储金币和技能点

技能冷却、状态效果等当前战斗临时数据不会写入存档。

旧版存档缺少新增字段时会使用默认值，尽量保持兼容。

## 项目结构

- `Program.cs`：程序入口、启动流程和主菜单
- `Player.cs`：玩家状态、资源、装备、技能和最终属性
- `Equipment.cs`：装备数据与强化/出售规则
- `EquipmentFactory.cs`：随机掉落装备生成
- `EquipmentManager.cs`：背包、装备和出售交互
- `Skill.cs`：技能数据与学习条件
- `SkillSystem.cs`：技能目录、学习菜单与技能执行
- `DamageCalculator.cs`：普通攻击和技能伤害计算
- `Monster.cs`：战斗中的怪物状态
- `MonsterFactory.cs`：怪物类型、等级、精英怪和属性成长
- `Battle.cs`：回合制战斗流程
- `LevelUp.cs`：经验结算与升级
- `Heal.cs`：非战斗治疗
- `ShowStatus.cs`：角色状态展示
- `Shop.cs`：城镇商店与装备强化
- `SaveData.cs`：JSON 存档、读档、删除和兼容处理
- `StatusEffect.cs` / `StatusEffectSystem.cs`：战斗状态效果
- `Tests/Console_RPG.Tests`：自动化测试项目

## 注释原则

注释优先解释“为什么这么设计”，而不是把代码逐行翻译成中文。

- 类注释说明职责。
- 关键方法说明设计原因。
- 数值规则说明具体含义。
- 容易出错的状态转换说明为什么这样处理。
- 不使用没有实际帮助的 XML `/// <summary>` 注释。

核心代码已经统一使用普通中文注释，方便隔一段时间重新打开项目时快速恢复上下文。

## 推荐阅读路线

如果隔了一段时间再回来，可以按：

`Program → Player → Battle → SkillSystem / EquipmentManager → MonsterFactory → SaveData`

这个顺序重新理解。

核心职责边界：

**UI/流程负责调用，Player 负责状态，Factory 负责创建，System 负责规则，SaveData 负责持久化。**
